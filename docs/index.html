On-premise Terraform operations platform

T-Helper

Платформа для обнаружения Terraform-проектов, учета репозиториев, локального security-анализа и управления runtime-конфигурацией.

README Архитектура
core API thelper
scanner *.tf discovery
worker jobs + leases
storage SQLite / PostgreSQL

Текущий baseline

Stage 05: repository manager MVP

Реализована backend foundation: entrypoints, storage adapters, migrations, runtime config, module lifecycle, jobs/workers/status, global scanning, scanner/registry HTTP API и clone/pull/sync workflows для репозиториев.

01

Проекты

Обнаружение Terraform working directories по наличию файлов *.tf.

02

Registry

Root paths, projects, links, repositories, environments и workspaces в БД.

03

Runtime

Персистентная конфигурация, lifecycle модулей и singleton runtime lock.

04

Repositories

Provider profiles, masked credentials, clone/pull/sync jobs и path safety.

Модель работы

Локальный контроль без передачи исходников наружу

Runtime-конфигурация и рабочие сущности хранятся в базе данных, а глобальный сканер не отправляет Terraform-код во внешние SaaS.

01 Root paths

Администратор задает области сканирования и ignore rules.

02 Global scan

Scanner регистрирует Terraform-проекты и ставит discovery jobs.

03 Project links

Проекты из одного Git repository связываются без merge записей.
