On-premise Terraform operations platform

T-Helper

A platform for Terraform project discovery, repository metadata, local security analysis and runtime configuration management.

Operating model

Local control without sending source code outside

Runtime configuration and working entities are stored in the database, and the global scanner does not send Terraform code to external SaaS services.

01 Root paths

Administrators define scan boundaries and ignore rules.

02 Global scan

The scanner registers Terraform projects and enqueues discovery jobs.

03 Project links

Projects from the same Git repository are linked without merging records.
